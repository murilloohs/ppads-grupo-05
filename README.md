# ValidaHoras

## Projeto de Prática Profissional em ADS

### Grupo 05

Sistema desenvolvido para a gestão e validação de horas, com foco em organização, controle e acompanhamento do uso de tempo em atividades acadêmicas e profissionais.

## Objetivo
Apresentar uma solução funcional e bem estruturada para registrar, validar e acompanhar horas, com base em requisitos definidos durante o processo de análise e prototipação.
